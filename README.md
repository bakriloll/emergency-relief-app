Emergency Relief System

A full stack application designed to help shelters and emergency centers manage incoming requests track inventory and allocate resources efficiently during crises.

Features:

Request intake system for people needing assistance
Inventory management for food, water, medicine, and supplies
Priority‑based allocation engine
Admin dashboard for monitoring and updates
Secure backend API with validation and structured data models

Tech Stack Used - 

Backend:

Node.js
Express.js
PostgreSQL

Frontend:

React
Modern UI components
API integration with backend
